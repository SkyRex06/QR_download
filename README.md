# VADEHI - Professional QR Link Generator

A clean, responsive, and client-ready web application built with React and Vite to generate high-resolution, scannable QR codes instantly in the browser.

## 🚀 Features

- **Direct URL Encoding**: Encodes exact URLs without third-party redirects or trackers.
- **Client Presentation Card**: Generates an executive presentation card branded with **VADEHI** in luxury typography.
- **100% Scanner-Safe**: QR modules remain completely unobstructed for guaranteed scan reliability across all devices.
- **High-Resolution PNG Download**: Download 1400px ultra-sharp PNG cards or standalone square QR codes.
- **Client-Side Privacy**: 100% in-browser generation with zero databases, zero cookies, and zero tracking.
- **Light & Dark Mode**: Responsive interface with modern theme toggling.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Vanilla CSS with modern custom design system
- **QR Generation**: `qrcode` (Error Correction Level H)
- **Icons**: `lucide-react`

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
